# Sutherland, 2026–2028

Цей приклад відтворює порівняння для поля `sutherland_nw` (42,9269° пн. ш., 95,5391° зх. д.). Він запускає добовий водний баланс Руслана на заздалегідь завантажених рядах і записує всі 28 варіантів у [результат](result.json). Підключення до інтернету під час запуску не потрібне.

## Запуск

З кореня розпакованого архіву, після встановлення залежностей із `requirements.txt`:

```bash
python replay_sutherland_2026_28.py \
  --output sutherland-result.json
```

Скрипт підключає [код Руслана з пакета](../../vendor/ruslan/README.md). Щоб звірити іншу копію, передайте її шлях через `--ruslan-dir`. Поле `engine_file_sha256` у результаті дає змогу звірити версію п’яти файлів рушія. Погодні ряди, параметри поля, довідник культур і температурний довідник теж є в пакеті.

## Як читати результат

- `water_shortfall_pct` — відсоток сезонної потреби культури у воді, який залишився незадоволеним за моделлю. Ділимо `deficit_mm` на `demand_mm` і множимо на 100. Для кукурудзи 2026 року це 182,418 мм із 535,999 мм, або 34,0%.
- `drought_stress_days` — кількість днів водного стресу за порогом рушія в межах сезону. Для тієї ж кукурудзи це 66 днів зі 133.
- `opening` і `closing` — запас води вище точки в’янення у всьому змодельованому профілі на початку та наприкінці сезону, в міліметрах. `recharge` зберігає перший день після кінця культури, коли запас досягнув 80% місткості профілю (127,84 мм). Для кукурудзи 2026 року модель оцінює кінець сезону 10 вересня, поповнення запасу — 18 вересня. `recharge_days: 0` означає, що поріг уже було досягнуто в останній день культури. `null` означає, що поріг не досягнуто у вікні спостереження. Для останньої культури пошук закінчується 31 грудня, для попередніх — напередодні наступної сівби.
- `rank_by_median_water_shortfall` показує всі чотири культури за медіаною розрахованого дефіциту. `top_eligible_by_water_shortfall` показує до трьох культур у тому ж порядку після вилучення тих, для яких відомий інтервал до повторної сівби коротший за довідковий (`below_reference_interval`). Наприклад, у 2028 році після соняшника 2027 року соняшник другий за водним розрахунком, а в добірці після перевірки чергування залишаються яра пшениця, кукурудза й соя. Стан перевірки кожної культури є в `rule`. Неповну історію або відсутність застосовного правила зберігаємо як окремі стани.
- У 2027 і 2028 є по два погодні сценарії. Вони демонструють чутливість до погоди і не задають імовірності подій. `finance` показує орієнтир FAOSTAT для США. Виручка розрахована з довідкової врожайності та ціни, без прогнозу врожаю за водним балансом.

Це окремий офлайн-розрахунок для відтворення конкретної історії поля. Маршрути кліматичного API можуть використовувати щоденні проєкції NASA NEX-GDDP-CMIP6, типове початкове наповнення та інший період розігріву моделі. Для відтворення саме цих чисел використовуйте команду вище.

## Історичні сезони й сценарії NASA для посіву 1 травня 2027 року

Після кукурудзи 2026 року порівнюємо яру пшеницю, кукурудзу, соняшник і сою за часткою потреби у воді, яку модель вважає незадоволеною. Для кожного із двох історичних сценаріїв зберігаємо змодельований запас води перед сівбою. В окремих прогонах підставляємо погоду ACCESS-CM2 або MPI-ESM1-2-HR за сценарієм SSP2-4.5 на 1 травня – 30 вересня 2027 року. У кожному прогоні культура завершила розвиток до кінця цього вікна. [Джерело проєкцій NASA](https://www.nccs.nasa.gov/data-collections/nex-gddp-cmip6/)

```bash
python replay_sutherland_2026_28.py \
  --nasa-2027
```

Файл [result-nasa-2027.json](result-nasa-2027.json) містить джерела, результати кожного прогону й окремі рейтинги. Погодні ряди й метадані NASA є у [nasa-2027.json.gz](nasa-2027.json.gz).

- `H` — медіана дефіциту за двома історичними сезонами 2019 і 2023 років.
- Для кожної моделі NASA рахуємо медіану дефіциту за двома прогонами з різним стартовим запасом води. `N` — медіана отриманих значень двох моделей NASA.
- `ensemble_score = (1 - nasa_weight) × H + nasa_weight × N`. Менший бал дає вищу позицію за пріоритетом «менше дефіциту води». Для демо обидві групи мають однакову вагу 0,5. Параметр `--nasa-weight` дозволяє перевірити чутливість рейтингу.

У групі історичних сезонів лідирує яра пшениця з дефіцитом 25,10%, за ACCESS-CM2 вона теж перша з 36,10%, а за MPI-ESM1-2-HR лідирує кукурудза з 55,40%. Зважений бал за формулою 50/50 становить 35,80 для ярої пшениці, 36,13 для кукурудзи, 37,33 для соняшника і 46,36 для сої.

### Що показати поруч із рейтингом

- `modeled_crop_days` — тривалість росту культури за моделлю. За історичними сценаріями медіана становить 134 дні для ярої пшениці й близько 143 для кукурудзи. Цей показник наближено описує, як довго на полі росте культура. Відсоток покриття поверхні листям потребує окремих даних.
- `water_shortfall_mm` і `drought_stress_days` — абсолютний дефіцит у міліметрах і тривалість стресу через нестачу води. За тих самих сценаріїв медіана днів стресу становить 71 для пшениці й 61 для кукурудзи. Тому підсумковий відсоток дефіциту й кількість днів стресу можуть давати різні рейтинги.
- Для ширшої оцінки сівозміни API окремо повертає винесення поживних речовин за наявності сумісної врожайності та оцінку ерозії за наявності всіх параметрів. Пропуски відображаються як відсутні дані. [Визначення сталого сільського господарства FAO](https://www.fao.org/sustainable-development-goals-data-portal/data/indicators/Indicator2.4.1-proportion-of-agricultural-area-under-productive-and-sustainable-agriculture/sdg-2-indicator-of-agricultural-sustainability/en)

Для поправки на орієнтацію схилу потрібні модель рельєфу та розрахунок прямої й розсіяної радіації.
