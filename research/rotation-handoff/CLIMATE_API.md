# API сівозмін для 2040-х

Робочий сценарій для UI та асистента описано в [інструкції вибору дати сівби](UI_AND_ASSISTANT.md). Обидва входи в інтерфейсі мають завершитися підтвердженою `planting_date`. Поточний кліматичний маршрут приймає готову дату. Автоматична рекомендація вікна, добір конкретного дня та кілька посівів в одному календарному році описані в інструкції як наступний етап інтеграції.

## Запуск

Встановіть залежності за [інструкцією запуску](README.md). За замовчуванням кліматичні маршрути використовують [код Руслана з пакета](vendor/ruslan/README.md). Для перевірки іншої версії можна задати `FIELDSHIFT_RUSLAN_DIR` на папку, де лежить `fstasks/balance.py`, і перезапустити сервер.

```bash
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8081
```

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8081
```

- `GET /api/rotations/climate/catalog` повертає поля, підтримувані культури, техніку, пріоритети та сценарії. `model_configured` підтверджує, що шлях до ядра задано.
- `POST /api/rotations/climate/step` порівнює варіанти для одного майбутнього сезону. Повертає метрики для всіх кандидатів і до трьох доступних виборів у `top_candidates`.
- `POST /api/rotations/climate/compare` порівнює дві або три готові сівозміни по два або три сезони. Усі плани мають однакові дати сівби та спільні кліматичні ряди. Сума дефіциту в міліметрах ділиться на суму потреби в міліметрах для кожної проєкції.

## Три кроки на одному полі

1. Надішліть [перший запит](examples/climate/api/sutherland-step-1.json). Сезон починається 1 травня 2040 року, `selected` порожній. Покажіть `top_candidates` з показниками й `ranking.status`. Повний список разом із причинами відсіву лежить у `candidates`.
2. Фермер обирає культуру. Для [другого сезону](examples/climate/api/sutherland-step-2.json) передайте цей вибір з датою сівби в `selected` і нову дату сівби. Дослівно переносіть `choice` з попередньої відповіді, додавши дату. Водна модель повторно програє вибраний перший сезон і період до нової сівби. У межах кожної кліматичної проєкції наступні кандидати стартують із того самого профілю запасу води.
3. Для [третього сезону](examples/climate/api/sutherland-step-3.json) передайте обидва попередні вибори й третю дату. Після третього вибору збережіть три сезони в застосунку. API зберігає стан у самому запиті. За потреби передайте дві чи три завершені гілки в [запит порівняння](examples/climate/api/sutherland-compare.json).

Пріоритет один у `farmer.priorities`. За замовчуванням ранжуємо за медіанним відсотком дефіциту серед вибраних кліматичних рядів. Альтернативи з відомою несумісністю техніки або надто раннім поверненням культури за місцевим джерелом залишаються у `candidates` із поясненням. Якщо вибраний пріоритет не можна порахувати для всіх придатних варіантів, `priority_unavailable` і `rank: null` позначають відсутність рейтингу. У такому разі `top_candidates` містить до трьох придатних варіантів у порядку запиту. В інтерфейсі їх можна показати як доступні варіанти.

```bash
curl -fsS http://127.0.0.1:8081/api/rotations/climate/step \
  -H 'Content-Type: application/json' \
  --data-binary @examples/climate/api/sutherland-step-3.json
```

## Підключення поля і клімату

Передайте `field_id` із каталогу або `field` з `latitude` і `longitude`. Для каталогу беремо збережений ґрунтовий профіль. За координатами отримуємо з SoilGrids об’ємний вміст води при польовій вологоємності й точці в’янення. Можна передати власні `soil_layers` і `soil_source`. Потрібно покрити щонайменше перший метр. Параметр `saturation` або є для всіх шарів, або відсутній для всіх. За наявності значень модель застосовує заданий коефіцієнт дренажу. За їх відсутності надлишок стікає в розрахунку тієї ж доби. [SoilGrids](https://www.isric.org/explore/soilgrids)

NASA NEX-GDDP-CMIP6 v2.0 дає найближчу клітинку `0,25°` та добові опади, мінімальну й максимальну температуру, відносну вологість, сонячну радіацію та вітер. За замовчуванням це ACCESS-CM2 за SSP2-4.5 і SSP5-8.5. Можна додати MPI-ESM1-2-HR або обрати один сценарій. Для календаря росту беремо історичну температуру NASA POWER за 1991–2020. Історична серія Marsden у пакеті охоплює 2023–2024 роки. Модель враховує накопичене тепло, потребу за фазами та водний баланс між посівами. Ядро працює за календарем весняно-літніх культур Північної півкулі, у цьому API південніше 70° пн. ш. Сівба з березня по липень, один посів на рік. Три рішення можуть охопити до п’яти календарних років. Результати є кліматичними сценаріями з датами моделі, а польова точність не встановлена. [NASA NEX-GDDP-CMIP6](https://www.nccs.nasa.gov/data-collections/nex-gddp-cmip6/) · [NASA POWER](https://power.larc.nasa.gov/docs/services/api/temporal/daily/) · [Параметри AquaCrop](https://ees.kuleuven.be/en/aquacrop/resources/reference-manual/annexesaquacropv73.pdf)

Пакет містить погодні входи Marsden за всі трикрокові комбінації 2040-х і Sutherland за 2040–2042 для ACCESS-CM2 за обома сценаріями. Для решти запитів потрібен доступ до джерел. Перше завантаження повних добових рядів може тривати до кількох хвилин. Повторний запит у тому самому процесі повторно використовує завантажені дані. У разі відсутності вихідних даних клієнт отримує HTTP 502 зі джерелом помилки. `weather_delivery` показує, чи дані взято з пакета або завантажено з NASA.

Перевірений приклад запиту за координатами у Франції з автоматичним профілем SoilGrids і даними NASA.

```json
{
  "field": {"latitude": 48.721, "longitude": 1.91},
  "planting_date": "2040-05-01",
  "scenarios": ["ssp245"]
}
```

## Метрики кожного кандидата

| Метрика | Поле й метод |
| --- | --- |
| Дефіцит води | `water.water_deficit_mm`, `water.water_deficit_pct` і деталізація `scenarios[case].metrics`. Це змодельована незадоволена потреба культури. |
| Стрес від дефіциту | `water.drought_stress_days` для медіани та `scenarios[case].metrics.drought_stress_days` для окремого ряду. Перезволоження і сумарний водний стрес повертаються порожніми. |
| Запас води й перерва | `profile_opening_mm`, `profile_closing_mm`, `fallow_days_before_planting`. `post_crop_recharge` показує, коли після завершення росту запас вперше сягнув 80% місткості до кінця року. На наступному кроці `recharged_to_80pct_after_previous_end_on` перевіряє весь проміжок до нової сівби. 80% є діагностичним порогом сценарію. |
| Повернення тієї самої культури | `agronomy.candidate` містить регіональну рекомендацію, її джерело й статус. `same_crop_return_reference_year` дає найраніший рік за нижньою межею джерела, якщо поле має відомий попередній посів цієї культури. |
| Поживні речовини | `agronomy.candidate.harvested_nutrients` містить винесення азоту, фосфору та калію за сумісної врожайності. За її відсутності `national_nutrient_reference` дає окремий довідковий орієнтир, якщо є відповідна країна й культура. У розрахунках немає концентрації цих речовин у ґрунті. |
| Живий покрив і ерозія | `water.living_cover_days` рахує змодельовані дні культури. Середньорічна ерозія з’являється за наявності повних `erosion` факторів RUSLE. Історичну ерозійність опадів показуємо окремим полем. |
| Урожайність і виручка | `economics` повертає довідкову врожайність, ціну та їхній добуток `gross_revenue_per_ha`. `price_reference_years` показує роки цін у довіднику. Погода 2040-х не змінює довідкову врожайність чи ціну. |
| Виручка після вартості насіння | `economics.revenue_after_seed_per_ha` віднімає від виручки лише `economics.seed_cost.cost_per_ha`. Обидві суми в одній валюті. За браком даних це поле має значення `null`. |

Універсального строку «відпочинку землі» немає. Наприклад, настанова щодо соняшнику в США вказує 3–4 роки між посівами соняшнику для зменшення тиску хвороб. Інші роки можна запланувати під іншими культурами. `observed_crop_history` окремо приймає спостережені попередні сезони, включно з відомим паром та фактичним урожаєм. Незаповнені роки в агрономічній історії залишаються невідомими. У водному сценарії між заданими майбутніми посівами розраховується період без живої культури зі змодельованими рештками. [Настанова Jefferson Institute щодо соняшнику, архів Iowa State](https://www.extension.iastate.edu/alternativeag/files/documents/sunflower_crop_guide.pdf) · [Розрахунки винесення FAOSTAT](https://files-faostat.fao.org/production/ESB/ESB_e.pdf#page=7)

Можна передати `hybrid` із назвою, джерелом і відомими параметрами. Щоб порівняти два варіанти однієї культури, передайте різні `choice_id` з однаковим `crop_id`. Якщо джерело дає тривалість усіх чотирьох фаз у `hybrid.stage_lengths`, модель використовує їх для календаря. Рейтинг стиглості з каталогу або назва гібриду самі по собі не змінюють водоспоживання. [Польове дослідження в Айові](https://doi.org/10.3390/rs14020394)

`GET /api/rotations/cultivar-references` повертає довідкові записи з випробувань. Можна фільтрувати за `crop_id`, `region_code` або обома параметрами. Наприклад, `?crop_id=soybeans&region_code=US-IA` поверне п’ять сортів, випробуваних у Sutherland. Поле `kind` позначає гібрид або сорт. Разом із назвою повертаються роки, місце, джерело та доступні виміряні параметри. У результаті кліматичного розрахунку є списки `agronomy.candidate.regional_hybrid_references` і `regional_cultivar_references` для відповідної культури й регіону.

| Культура і регіон | Що є в довіднику |
| --- | --- |
| Соняшник, Північна Дакота (`US-ND`) | 5 гібридів, дні від сівби до цвітіння і стиглості у випробуванні в Carrington. [NDSU](https://www.ag.ndsu.edu/energy/variety-trials/carrington-rec/2025%20trial%20results/2025-trial-results-sunflower-oil-carrington/at_download/file) |
| Ярий ріпак, Північна Дакота (`US-ND`) | 4 гібриди, дні до цвітіння й стиглості та тривалість цвітіння у випробуванні в Hettinger. Ріпак є в загальному каталозі. [NDSU, таблиця 5](https://www.ndsu.edu/agriculture/sites/default/files/2025-12/a1125-25.pdf#page=5) |
| Соя, Айова (`US-IA`) | 5 сортів, група стиглості та врожайність у випробуванні в Sutherland. [Iowa Crop Performance Tests, таблиця 6](https://croptesting.iastate.edu/Soybean/Docs/2025_ISU_soybean_final_report.pdf) |
| Яра пшениця, Південна Дакота (`US-SD`) | 3 сорти, врожайність у випробуванні в Brookings. [SDSU, таблиця випробувань](https://extension.sdstate.edu/sites/default/files/2025-09/S-0002-2025-04-SW-Brookings.pdf#page=2) |

Дні до цвітіння й стиглості стосуються наведеного місця, року й дати сівби. Група стиглості сої є класифікацією. Врожайність із випробувань також показується окремо. Ці поля довідника не підставляються автоматично в календар, водний розрахунок чи оцінку виручки.

Кліматичний розрахунок підтримує сім культур: кукурудзу на зерно, сою, соняшник, яру пшеницю, ячмінь, картоплю та цукровий буряк. Ширший каталог `/api/rotations/forecast/catalog` має 13 профілів. Гібрид залишається варіантом своєї культури. Для його окремої ціни потрібен власний `seed_cost`. Інакше, за наявності, застосовується базовий бюджет насіння цієї культури.

Для [перевірки фінансових показників](examples/climate/api/marsden-revenue.json) подайте `farmer.priorities: ["revenue"]` або `farmer.priorities: ["revenue_after_seed"]`. Обидва показники доступні в кожній картці за наявності входів. Для каталогових полів Айови за замовчуванням використовуються рядки вартості насіння кукурудзи й сої з бюджету Iowa State за 2026 рік. Для соняшнику й ярої пшениці орієнтир взято з бюджету південного сходу Північної Дакоти за 2026 рік. За наявності власної ціни передайте `seed_cost` у кандидаті чи виборі сезону, вказавши `cost_per_ha`, `currency` та `source`. Для рейтингів виручки потрібні порівнювані суми в одній валюті. [Бюджет Iowa State](https://www.extension.iastate.edu/agdm/crops/pdf/a1-20.pdf) · [Бюджет NDSU](https://www.ndsu.edu/agriculture/sites/default/files/2026-02/ec1659.pdf)

Ціни в пакеті є історичними орієнтирами. Sutherland використовує національні дані США FAOSTAT за 2022–2024 для кукурудзи, сої, соняшнику й пшениці. Marsden використовує джерела USDA за маркетинговий 2024 рік. Рік бюджету насіння й рік ціни продажу відображаються окремо. USDA вже опублікувало новіші національні фінальні ціни за 2025/26. Вони доступні для звірки й ручних припущень через `economics`, а довідковий набір цього пакета зберігає свої початкові роки та рівень географії. [FAOSTAT Producer Prices](https://www.fao.org/faostat/en/#data/PP) · [Національні ціни USDA](https://www.fsa.usda.gov/sites/default/files/2026-11/2026_MYA.pdf)

## Результат прикладу Sutherland

| Сівозміна 2040–2042 | Медіанний дефіцит | Медіана днів стресу від дефіциту |
| --- | ---: | ---: |
| Кукурудза → соняшник → соя | 37,87% | 193,5 |
| Соняшник → соя → кукурудза | 39,27% | 203 |
| Соя → кукурудза → соняшник | 38,80% | 196 |

Два прогони ACCESS-CM2 дають два цілі підрахунки днів на план. Медіана може бути дробовою, наприклад 193,5 — середина між 189 і 198. Повний результат кожного сценарію є у відповіді. Календарі цього API відрізняються від календаря окремого [експерименту Marsden за десятиріччя](CLIMATE_2040S.md). Для порівняння користуйтесь результатами одного методу з однаковими введеними параметрами.
