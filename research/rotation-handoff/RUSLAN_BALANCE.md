# Порівняння за готовим водним балансом

Застосунок може передати добові результати Руслана у `POST /api/rotations/compare-water-balances`. Маршрут працює із записами запиту локально. Він обчислює дефіцит, тривалість стресу, окремі показники ґрунту та рейтинг за обраним пріоритетом.

Візьми [готовий запит для F‑03](examples/f03-ruslan-balance.json). Він містить 16 діб, з 2 по 17 липня 2025, для кукурудзи та сої з `task3_flowering_f03_2025.json`. Це історичний прогін на архівній погоді NASA POWER. Його вихідні добові суми становлять 89,53 мм для кукурудзи та 88,60 мм для сої. Для обох культур дефіцит і дні сухого стресу дорівнюють нулю в цьому вікні. Дні стресу від перезволоження мають значення `null`. Приклад демонструє зіставлення двох культур за 16 діб.

## Як підготувати добові записи

Для порівняння повних планів експортуй добові `DayResult` із `fstasks/rotations.py` через `run_window(...)[ "days" ]` або з `fstasks/balance.py` через `simulate`. Для прогнозу після наявного горизонту можна брати `members[].days` кожного погодного сценарію до зведення в перцентилі. Подавай показники з повною числовою точністю.

| Поле запиту | Звідки й навіщо |
|---|---|
| `date` | Дата доби. Кожен план передає всі дати періоду в порядку. |
| `cover` | Культура з `DayResult.cover`. Для `fallow` передай `null`. Дні без культури пропускаються в метриках стресу й дефіциту. |
| `etc_mm` | Потреба у воді, мм/добу. |
| `eta_mm` | Змодельоване фактичне водоспоживання, мм/добу. |
| `stress` | Добовий прапорець сухого стресу з моделі Руслана. Він враховує правила моделі для фаз росту. |
| `wet_stress` | Ознака стресу від перезволоження за окремою моделлю аерації. У поточному експорті Руслана її немає, передай `null`. |
| `irrigation_mm` | Полив за добу, мм. Передай той самий графік для всіх погодних сценаріїв одного плану. |
| `gap` | `true`, якщо вхідні дані доби були заповнені, `false` якщо заповнення не було, або `null` якщо експорт про це не повідомляє. |

`scenarios` задає спільні сценарії з джерелом погоди та типом даних. `model_source` описує виробника та версію водного балансу. До одного запиту передавайте плани для одного поля, з однаковими погодними сценаріями та спільним періодом. `plans[].members` містить добові записи кожного сценарію. У `farmer.priorities` можна передати один із шести пріоритетів. Для рейтингу також потрібні підтверджені вимоги до техніки й, за наявності поливу, його доступність.

## Що повертаємо

- **Дефіцит** — сума добових `max(0, etc_mm − eta_mm)`. Частка дефіциту — ця сума, поділена на суму потреби за дні культури. За нульової потреби повертаємо `null`.
- **Сухий стрес** — кількість днів з ознакою `stress`. Для спільного водного стресу рахуємо дні з хоча б однією ознакою й ділимо на дні культури. Якщо ознаки перезволоження бракує хоч в один день культури, спільне значення цього сценарію лишається порожнім. Пріоритет `water_stress` доступний за повної оцінки всіх планів. Для рейтингу беремо медіану за сценаріями.
- **Ерозія** — окрема середньорічна оцінка з `soil.erosion`, коли передані узгоджені коефіцієнти RUSLE й джерело. Дні живого покриву беруться із `soil.living_cover`, винесення з урожаєм — з `soil.harvests`. Орієнтовна врожайність і виручка беруться з явно переданого `economics`.

Архів Руслана містить готовий приклад F‑03 і код повного добового прогону. Для [порівняння Marsden на 2040-ві](CLIMATE_2040S.md) у цьому пакеті є добові проєкції NASA, профіль ґрунту SSURGO, параметри соняшнику й інструкція запуску ядра Руслана.
