# API оцінки сівозмін за історичною погодою

`GET /api/rotations/assessment/catalog` повертає сценарії, культури та плани зі стабільними ідентифікаторами й номерами. У `fields` є доступні ділянки, координати ділянок і погодної сітки, посилання на джерела та роки відбору.

| Номер | Ідентифікатор | Культура або план |
|---|---|---|
| 1 | `maize_grain` | Кукурудза на зерно |
| 2 | `sunflower` | Соняшник |
| 1 | `marsden-a` | Кукурудза → соняшник |
| 2 | `marsden-b` | Соняшник → кукурудза |

`POST /api/rotations/assessment` приймає такий JSON.

```json
{
  "field_id": "marsden_demo",
  "rotation_ids": ["marsden-a", "marsden-b"],
  "scenarios": ["baseline", "drought", "heat"]
}
```

`field_id` вибирає ділянку. У ZIP є `marsden_demo` (Marsden Farm), `sutherland_nw` (Northwest ISU-RDF, Sutherland) і `crawfordsville_se` (Southeast ISU-RDF, Crawfordsville). Ідентифікатори `marsden-a` та `marsden-b` збережені для сумісності й задають порядок культур для будь-якої вибраної ділянки. [Як додати ділянки](README.md#додавання-ділянок)

| Сценарій | Відбір року за погодою від 1 травня до 30 вересня |
|---|---|
| `drought` | Рік з найменшою сумою опадів у вибірці ділянки. |
| `heat` | Серед решти років обирається рік із найбільшою кількістю днів із Tmax ≥ 32 °C. За однакової кількості першим іде рік з вищою середньою Tmax. |
| `baseline` | Серед років, що лишились, обирається найближчий до медіанної суми опадів і медіанної кількості спекотних днів. Кожен показник порівнюється відносно його розмаху у вибірці. |

У пакеті `reference_years` охоплює 2017–2026 роки. Дані 2016 року використовуються як попередній сезон для вікна, що закінчується у 2017 році. У `results[].scenario` поле `criterion` описує правило відбору, `analog_year` показує вибраний рік, а `replay_years` містить два фактичні послідовні роки, попередній і обраний. Обидва плани розраховуються на тому самому дворічному вікні. `rain_mm`, `hot_days` і `mean_tmax_c` описують обраний рік за період відбору. Позначки «звичайний», «посушливий» і «спекотний» описують цю недавню вибірку.

Рік визначає, який добовий ряд використати й які дати повернути. Коефіцієнти водоспоживання залежать від культури й дня після сівби. Якщо перенести той самий добовий ряд і початкову вологість у інший рік, та сама культура на тому самому ґрунті дає той самий дефіцит і ті самі строки цвітіння від дня сівби. Перевірка в пакеті відтворює це для обох культур і обох планів на трьох ділянках. [Як запустити перевірку](README.md#перевірка-результату-між-роками)

Для розрахунків використано добові опади, мінімальну й максимальну температуру та еталонне випаровування ERA5-Seamless через Open-Meteo в UTC. Це історичні оцінки для комірок сіткового реаналізу. Усі три сценарії використовують архівні значення погоди без синтетичних рядів і поправок, що позначено як `weather_adjustment: none`. Початкова вологість береться за 30 квітня кожного року й переводиться в міліметри доступної води за профілем ґрунту відповідної ділянки. Для обох культур дата сівби задана як 1 травня. Тривалість фаз для коефіцієнта водоспоживання задана в днях. Модель розраховує кожен сезон окремо з його початковою вологістю. [Історичний API Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api)

- `water_shortfall.value_pct` — частка незадоволеної потреби у воді за сценарію. Для плану це сумарний дефіцит у міліметрах, поділений на сумарну потребу за два роки. Метод `formula`. [FAO-56](https://www.fao.org/4/X0490E/x0490e0e.htm)
- `modeled_yield_loss_due_to_water.value_pct` — сезонна частка дефіциту води, помножена на коефіцієнт чутливості FAO для культури. Показник плану є середнім двох сезонних оцінок. Метод `model`. Прямий вплив спеки на врожай не входить у розрахунок. [FAO Crop yield response to water](https://www.fao.org/4/i2800e/i2800e.pdf)
- `yield_risk.value_pct` — зарезервоване поле для ймовірності втрати врожаю понад погоджений поріг. Зараз `null`. Для оцінки потрібні спостереження врожайності за культурами, полями, роками і сценаріями, визначення події та перевірка моделі.
- `fertilizer` — окремі норми N, P₂O₅ і K₂O у кг/га. Зараз `null`. Для розрахунку потрібні дані аналізу ґрунту, культура, попередник, ціль врожайності там, де її потребує метод, та локальна методика. [Приклад методики для Айови](https://crops.extension.iastate.edu/files/article/PM1688.pdf)

У `projection` метод `historical_replay_range` і поле `window_count` описують історичну вибірку з 10 дворічних вікон. У `projection.rotations` кожен запис має `rotation_id`, `water_shortfall` і `modeled_yield_loss_due_to_water`. Обидва показники містять `minimum_pct`, `median_pct`, `maximum_pct`, `method` і `accuracy`. Цей діапазон описує зміну оцінок за різних історичних умов. Для прогнозу на майбутній період потрібен окремий прогноз погоди або інша модель, перевірена для прогнозного горизонту.

`accuracy: not_validated_for_field` означає, що похибку не оцінювали на польових вимірюваннях вибраної ділянки. Поле `validation_error_pct_points` залишається `null`, доки такої перевірки немає. Для графіка за роками та культурами можна використовувати `crop_seasons`, де також є оцінене вікно цвітіння й кількість днів нижче порога водного стресу.

## Коефіцієнт водоспоживання соняшнику

У версії 2.1 потенційна потреба соняшнику розрахована для густого посіву. Коефіцієнт становить 0,35 у перші 25 днів, зростає до 1,15 за наступні 35 днів, тримається на 1,15 протягом 45 днів і спадає до 0,35 за останні 25 днів. Для рідшого богарного посіву FAO наводить нижче значення середини сезону. [FAO-56, таблиці 11 і 12](https://www.fao.org/4/x0490e/x0490e0b.htm)

На польових дослідах із поливом у Колорадо середня абсолютна розбіжність сезонного водоспоживання зменшилась із 60,9 до 47,5 мм у 2008 і 2010 роках та з 59,1 до 37,8 мм у 2014–2015 роках. Розбіжність показника дефіциту API зі зниженням водоспоживання відносно добре политого контролю зросла з 5,3 до 11,0 відсоткового пункта у 2008 і 2010 роках. Цей польовий орієнтир використовує водоспоживання контрольної ділянки як знаменник, а API використовує розрахункову потребу без водного стресу. Похибка для Marsden невідома. [Польові дані USDA](https://doi.org/10.15482/USDA.ADC/28586066.v2)
