# Rotation handoff provenance and scope

This installed adaptation preserves the calculations from the Field Shift team
research/rotation-handoff at a68b67c70a470bf8a5ba8f9f8e59350f029200fc. Its original
directory remains unmodified. The complete source-file receipt is packaged.
Ruslan's engine source is nasa_preparation468a03d79e596e9daab4cfdb20e9e0c8e2b83a92.
Team code reuse was requested by the repository owner; no upstream licence file
was supplied for that engine. This notice does not grant third-party rights.
Individual packaged public references retain their original source/license fields.

Adaptations: unique installed namespace, resource access, no cwd field discovery,
no dynamically imported engine directory, bounded private process execution,
explicit anonymous provider acquisition and immutable offline replay. Scientific
assumptions and formulas remain separate from deployment and empirical gates.
No model is promoted to validated yield, profit or global sowing recommendation.
The original synthetic weather helpers remain for research traceability but are
not used by the service's allowlisted operations.

The optional Strategies mode extends the installed adaptation with sourced
dry pea, oat and millet thermal profiles and an adaptive net irrigation policy.
The original receipt identifies the upstream research files. The runtime's
installed engine hash and each climate result's balance-source hash identify
the executed adaptation. The new profiles remain uncalibrated scenario inputs.
