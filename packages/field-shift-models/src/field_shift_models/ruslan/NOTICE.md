# Team research provenance

The model text files and original metadata are unchanged artifacts from Ruslan
Koritich's private team repository `nasa_preparation`, branch
`research/fieldshift-tasks-1-4`, commit
`468a03d79e596e9daab4cfdb20e9e0c8e2b83a92`, under
`research/fieldshift_tasks/outputs/real/task1_model/`.

The narrow feature calculations and prediction arithmetic in this adapter are
adapted from that commit's `fstasks/moisture_map/real.py:site_features`,
`robust.py:RobustData._z_features` and `serve.py:Released.estimate`.
The original research remains Ruslan's work. No new public redistribution license
is asserted; none was found in this private source checkout. LightGBM itself is
an independently distributed optional dependency with its own terms.

`assets/provenance.json` pins all retained bytes and relevant upstream source
hashes. The source's FROZEN.json differs from five current source files; its old
fresh-test report does not validate this exact revision. The original raw data
was not supplied. Original `publish:true` metadata is retained verbatim as source
history, and is deliberately never honored as an application promotion decision.

This is a delayed historical surface reconstruction research adapter, not a
nowcast, seasonal forecast, root-zone reserve, crop yield or a validated regional
product. No empirical accuracy or calibrated coverage was reproduced here.
