# Стан проєкту

## Поточна готовність — 2026-11-14

У репозиторії є повний склад застосунку: API, web, приватний асистент і widget, ML-пакет, усі десять міграцій БД, тести, ресурси, Compose, резервне копіювання та CI/release workflows. Готовність компонентів і результати перевірок наведені нижче.

Загалом у перелічених suites успішно виконано **1188 тестів**. Пропуски не зараховано як успішні результати. Окремі smoke-перевірки не додаються до цього числа.

### Межі перевірки

- Docker daemon відсутній: образи не збиралися, весь Compose-стек не запускався. PostgreSQL 17 / Redis 7.4 з Compose потребують контейнерної перевірки; локальні інтеграційні результати отримано на версіях 18.6 / 8.0.5.
- Опційні embeddings і dense/reranker моделі не встановлювалися; дороге навчання не запускалося.
- Живі платні Gemini/OpenAI/Anthropic не викликалися. Для перевіреного scripted-llm режиму ваші ключі не потрібні. Налаштування живих провайдерів описані в [інтеграції асистента](assistant-integration.md).
- Unit-запуски можуть повідомляти про deprecation у залежностях; web/widget build попереджає про великі chunks.
- Оцінка production-готовності й комерційних умов джерел даних залишається окремою роботою.
